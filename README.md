# 小吴手绘汽车

面向 16 岁少年、对标汽车设计专业预科的分步手绘教程网站（31 课 / 7 单元 / 150 张步骤插画）。
课程结构内化了清华大学《汽车造型设计二维表达》公开课（王波）的教学体系：
比例与结构 → 透视与视角 → 新能源设计语言 → 渲染与表现 → 创作与作品集 → 实车写生与材质 → 专业技法与数字化进阶。

## 课程结构（7 单元 · 31 课）

1. 单元一 · 比例与结构（第 1~4 课）
2. 单元二 · 透视与视角（第 5~8 课）
3. 单元三 · 新能源设计语言（第 9~12 课）
4. 单元四 · 渲染与表现（第 13~16 课）
5. 单元五 · 创作与作品集（第 17~20 课）
6. 单元六 · 写生与材质（第 21~25 课：实车写生、构图版面、金属/玻璃/塑料材质写生）
7. 单元七 · 专业技法与进阶（第 26~31 课：色粉、底色高光、精细外饰/内饰、CAS 数字化、考前作品集）
