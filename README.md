# 小吴手绘汽车

面向 16 岁少年、对标汽车设计专业预科的手绘教程网站。首页三大栏目：课程、流行车辆手绘、大师示范。

## 大师示范

`master.html` 收录两段专业手绘示范视频（B 站官方播放器内嵌，版权归原作者）：

- 《【工业设计手绘】汽车手绘速写示范》· 设计手绘考研小站（铅笔线稿速写全过程）
- 《从几何体开始画车》· 首象工业设计（几何体起型法，零基础友好）

每个视频附“跟着看”清单，看完后回到五个视角课程练习。

## 网站结构

1. 课程：正视图、侧视图、后视图、斜视图、舱内图五门跟画课程（每门含分步过程图 + 成品图）
2. 流行车辆手绘：尊界、问界三视图（正视图 / 后视图 / 侧视图）
3. 大师示范：B 站官方播放器内嵌两段专业手绘教学视频
